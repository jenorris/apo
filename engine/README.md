# apo-engine

Python engine for [Apo](../README.md) — local hybrid search (sqlite-vec BM25 + dense
vectors) and surgical writes over a Markdown/YAML vault, plus the stdio MCP server
(`mcp/server.py`), local RPC, and the vault watcher (sole `index.db` writer).

See the repo root `README.md` and `docs/quickstart.md` for install and usage.
